# Markiro signer

## Автозапуск в Windows

На вкладке «Состояние» галочка «Запускать при входе в Windows» включает или
отключает запуск агента в трее для текущего пользователя. Смена настройки
применяется сразу. Она не останавливает уже запущенный агент и не зависит от
привязки к организации или выбранного сертификата.

При первой установке автозапуск включён. Интерфейс читает запись
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\MarkiroSigner` через Rust;
браузерное хранилище не используется. Путь к исполняемому файлу заключён в кавычки.
Выбор дополнительно записывается в DWORD `AutostartEnabled` ключа
`HKCU\Software\Markiro\Signer`, чтобы NSIS сохранял его при обновлении или
повторной установке поверх существующей. Обычное удаление очищает обе записи,
удаление в режиме обновления сохраняет их.

При ошибке чтения галочка недоступна до успешного повтора. При ошибке записи
интерфейс показывает сообщение и перечитывает регистрацию, поскольку часть
операции могла выполниться. Вне Windows команды возвращают ошибку.

## Проверка на Windows перед выпуском

1. Установить NSIS-пакет в путь с пробелами и кириллицей. Убедиться, что галочка
   включена, а после выхода и входа в Windows агент появляется в трее.
2. Снять галочку, полностью выйти из агента и снова открыть его: выбор сохранён.
   После выхода и входа в Windows агент не запускается.
3. Обновить отключённый агент через встроенный updater, затем повторить установку
   поверх существующей. Галочка остаётся снятой, запись Run отсутствует.
4. Включить галочку и повторить обновление: агент снова запускается при входе.
5. Удалить приложение обычным способом: запись Run и предпочтение удалены.
6. Выполнить `cargo test --manifest-path apps/signer/Cargo.toml --workspace`.
   Windows-тест автозапуска использует изолированное поддерево реестра и проверяет
   включение, повторное отключение, кавычки, Unicode и сохранность чужих записей.

Тесты UI используют подмену native bridge. Компиляция для Windows и Cargo-тесты
на другой ОС не заменяют проверку входа в Windows и поведения NSIS.
