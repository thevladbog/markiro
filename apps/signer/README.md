# Markiro signer

## Автозапуск в Windows

На вкладке «Состояние» галочка «Запускать при входе в Windows» включает или
отключает запуск агента в трее для текущего пользователя. Смена настройки
применяется сразу. Она не останавливает уже запущенный агент и не зависит от
привязки к организации или выбранного сертификата.

При первой установке автозапуск включён. Интерфейс читает запись
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\MarkiroSigner` через Rust;
браузерное хранилище не используется. Путь к исполняемому файлу заключён в кавычки.
Выбор дополнительно записывается в DWORD `AutostartEnabled` ключа
`HKCU\Software\Markiro\Signer`, чтобы NSIS сохранял его при обновлении или
повторной установке поверх существующей. Обычное удаление очищает обе записи,
удаление в режиме обновления сохраняет их.

При ошибке чтения галочка недоступна до успешного повтора. При ошибке записи
интерфейс показывает сообщение и перечитывает регистрацию, поскольку часть
операции могла выполниться. Вне Windows команды возвращают ошибку.

## Проверка на Windows перед выпуском

1. Установить NSIS-пакет в путь с пробелами и кириллицей. Убедиться, что галочка
   включена, а после выхода и входа в Windows агент появляется в трее.
2. Снять галочку, полностью выйти из агента и снова открыть его: выбор сохранён.
   После выхода и входа в Windows агент не запускается.
3. Обновить отключённый агент через встроенный updater, затем повторить установку
   поверх существующей. Галочка остаётся снятой, запись Run отсутствует.
4. Включить галочку и повторить обновление: агент снова запускается при входе.
5. Удалить приложение обычным способом: запись Run и предпочтение удалены.
6. Выполнить `cargo test --manifest-path apps/signer/Cargo.toml --workspace`.
   Windows-тест автозапуска использует изолированное поддерево реестра и проверяет
   включение, повторное отключение, кавычки, Unicode и сохранность чужих записей.

Тесты UI используют подмену native bridge. Компиляция для Windows и Cargo-тесты
на другой ОС не заменяют проверку входа в Windows и поведения NSIS.

## Где хранятся данные

Агент хранит `signer.json` (привязку, выбранный сертификат и секрет агента под
DPAPI) и журнал в `%LOCALAPPDATA%\app.markiro.signer\`. Версии по 0.1.4 включительно
держали их в перемещаемом `%APPDATA%\app.markiro.signer\`; при первом запуске
новой версии данные однократно переносятся, запись о переносе лежит рядом в
`signer-storage.json`.

Перемещаемая папка не годится: при перемещаемом профиле или перенаправленном
AppData она вместе с ключами DPAPI пользователя попадает на другие компьютеры,
и второй компьютер становится тем же агентом. Агент остаётся в перемещаемой
папке и объясняет почему на вкладке «Состояние» только при временном или
обязательном профиле и при политике удаления локальных копий профиля при
выходе.

Для ИТ-службы: на компьютере с УКЭП используйте локальную учётную запись или
профиль без перемещения и перенаправления AppData; привязывайте агента после
развёртывания образа диска, а не до.

Возврат на версию до переноса делается вручную: скопировать `signer.json`
обратно в `%APPDATA%\app.markiro.signer\` и удалить `signer-storage.json`.

### Если агент работал на нескольких компьютерах

Перенос не разделяет агента, которого перемещаемый профиль уже скопировал на
другой компьютер. Признак — сообщение на вкладке «Состояние» о копии привязки
этого агента в перемещаемом профиле. Порядок действий:

1. Отозвать агента в кабинете. Каждая копия получит отказ и вернётся к экрану
   привязки. Отзыв удаляет токен Честного ЗНАКа организации, поэтому обмен с
   ЧЗ приостановится до первого обновления токена новым агентом.
2. Привязать заново только компьютер с квалифицированным сертификатом.
3. Удалить в профиле пользователя `%APPDATA%\app.markiro.signer\` и папки
   `%APPDATA%\app.markiro.signer.retired-*`, если они есть: иначе сообщение о
   копии в перемещаемом профиле будет появляться при каждом запуске.

Папка `app.markiro.signer.retired-*` остаётся, если во время переноса другой
компьютер успел изменить `signer.json` или в старой папке лежали посторонние
файлы. Деинсталлятор её не удаляет: флажок «Удалить данные приложения»
убирает только `%APPDATA%\app.markiro.signer` и
`%LOCALAPPDATA%\app.markiro.signer`.
