# Bundled fonts

IBM Plex Sans and IBM Plex Mono, © IBM Corp., licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Static TTFs taken from the IBM Plex repository
(https://github.com/IBM/plex, `packages/plex-sans` and `packages/plex-mono`) with
`tools/fetch-fonts.sh`. Bundled so the handheld renders without any network dependency
(AGENTS.md: offline factory path).
