# Образцы этикеток

Библиотека для ручного создания шаблонов у конкретного тенанта: выберите образец,
создайте этикетку в Markiro и вставьте код через **«Импорт кода»**.
Откройте [галерею с превью и кнопками копирования](index.html) в браузере.
Переключатель «Полное наименование / Наименование для печати» меняет поле
во всех макетах с названием: `{{product.name}}` или `{{product.printName}}`.
Выбор применяется к видимому, копируемому и скачиваемому коду. По умолчанию
выбрано наименование для печати. Этикетки 30×20 мм не содержат названия
и при переключении не меняются. В демонстрационных данных оба названия
совпадают, поэтому PNG остаются одинаковыми.

## Категории и размеры

Для каждой категории подготовлены одинаковые десять размеров и назначений.
В папках лежат исходники `.zpl` и соответствующие демонстрационные `.png`.

| Категория                  | Группа ЧЗ | Папка                             |
| -------------------------- | --------- | --------------------------------- |
| Соки                       | 23        | [juices](juices/)                 |
| Пищевые растительные масла | 33        | [vegetable-oils](vegetable-oils/) |
| Косметика                  | 35        | [cosmetics](cosmetics/)           |

| Назначение в Markiro | Размер, мм | Имя файла            | Содержимое                                          |
| -------------------- | ---------- | -------------------- | --------------------------------------------------- |
| Дубликат товара      | 30 × 20    | `unit-30x20.zpl`     | Data Matrix, краткая категория, даты                |
| Дубликат товара      | 58 × 40    | `unit-58x40.zpl`     | Data Matrix, название, GTIN, даты                   |
| Дубликат товара      | 75 × 120   | `unit-75x120.zpl`    | То же и номер смены                                 |
| Коробка              | 58 × 40    | `box-58x40.zpl`      | SSCC, название, GTIN, даты, количество              |
| Коробка              | 75 × 120   | `box-75x120.zpl`     | То же и номер смены                                 |
| Коробка              | 100 × 100  | `box-100x100.zpl`    | То же и номер смены                                 |
| Коробка              | 100 × 150  | `box-100x150.zpl`    | То же и номер смены                                 |
| Паллета              | 100 × 100  | `pallet-100x100.zpl` | SSCC, название, GTIN, даты, смена, коробов и единиц |
| Паллета              | 100 × 150  | `pallet-100x150.zpl` | То же, крупнее                                      |
| Паллета              | 148 × 210  | `pallet-148x210.zpl` | То же в формате A5 логистической этикетки GS1       |

Мелких паллетных форматов нет намеренно: паллетную этикетку читают через
проезд, а не с руки, поэтому самый маленький здесь — 100 × 100, а 148 × 210
соответствует A5 логистической этикетки GS1. Два счётчика — **коробов** (`qty.boxes`) и
**единиц** (`qty`) — стоят рядом и одинаково крупно: приёмщик пересчитывает
короба со штабеля и сверяет их с этикеткой, а число единиц сверяет следующая
система. Единицы приходят с суффиксом «шт.», короба — с «кор.», поэтому пара
читается однозначно даже там, где подпись не попала в поле зрения.

## Как использовать для тенанта

1. В кабинете нужного тенанта откройте раздел этикеток и создайте новую этикетку.
2. Укажите название, например «Сок — дубликат 58×40», и **до импорта** выберите
   назначение из таблицы. У сохранённого шаблона назначение менять нельзя.
3. Ограничьте область применения нужной товарной группой. Текст «СОКИ» в макете
   сам по себе не задаёт область применения: код импорта содержит только геометрию
   и элементы этикетки.
4. Нажмите **«Импорт кода»**, выберите **ZPL, 203 DPI**, вставьте файл целиком
   от `^XA` до `^XZ` и примените импорт. Размер задаётся исходником; дробные доли
   миллиметра после импорта — округление до целого количества точек.
5. Проверьте превью и сохраните шаблон. При необходимости назначьте его шаблоном
   по умолчанию для этой группы и назначения. Настройка действует на всю группу
   ЧЗ: если в ней есть другие виды продукции, выбирайте образец для конкретной
   смены, чтобы заголовок категории соответствовал товару.
6. Выберите его в нужном производственном сценарии. Напечатайте пробную этикетку
   на целевом принтере и проверьте код сканером, включая полный КМ у дубликата.

**Эти `.zpl` — исходники импорта Markiro, а не готовое задание принтеру.**
В частности, `^BX` у дубликата здесь задаёт размер всего квадрата в модели
Markiro. Не отправляйте эти файлы напрямую принтеру. Готовые ZPL/TSPL генерирует
Markiro после подстановки данных. DPI импорта описывает координаты исходника;
разрешение и язык реального принтера настраиваются отдельно.

## Что подставляется при печати

| Поле в коде              | Источник                                                                     |
| ------------------------ | ---------------------------------------------------------------------------- |
| `{{product.name}}`       | Полное название товара                                                       |
| `{{product.printName}}`  | Печатное название товара                                                     |
| `{{product.gtin}}`       | GTIN товара                                                                  |
| `{{km.code}}`            | Полный исходный код маркировки единицы, включая разделители GS и криптохвост |
| `{{sscc}}`               | SSCC короба или паллеты; в штрихкоде печатается GS1-128 с AI 00              |
| `{{date}}`, `{{expiry}}` | Дата изготовления и срок годности из текущего сценария печати                |
| `{{qty}}`                | Количество единиц: в коробе — его содержимое, на паллете — сумма по коробам  |
| `{{qty.boxes}}`          | Количество коробов на паллете; на коробе и дубликате пусто                   |
| `{{shift.no}}`           | Номер смены                                                                  |

Демонстрационные SSCC в превью различаются первой цифрой не случайно: Markiro
режет серии коробов с расширения `0`, а паллет — с `1`
(`BOX_EXTENSION_DIGIT` / `PALLET_EXTENSION_DIGIT`), и эти пространства не
должны пересекаться. В самом коде остаётся переменная `{{sscc}}` — эти номера
в шаблон не попадают.

Образцы не создают новые КМ, SSCC, товары или связи агрегации. Назначение
«Дубликат товара» повторяет существующий КМ одной единицы. Расчёт дат остаётся
в приложении; если используется срок хранения в днях, день изготовления
считается первым днём. Демонстрационные даты в PNG не задают срок хранения товара.
Если срок хранения товара не заполнен, дата годности может остаться пустой:
перед печатью заполните срок либо уберите соответствующий блок из шаблона.

Название ограничено одной строкой: для длинного названия заполните короткое
печатное название или выберите больший формат. В 30×20 мм названия и GTIN нет;
даты набраны мелко, поэтому этот формат особенно важно проверить на принтере.
Все размеры — отправная точка для настройки под носитель и оборудование тенанта.

ЕГАИС и «дата розлива» в макеты не включены. Это рабочие наклейки с кодами:
полная потребительская этикетка с составом, INCI, изготовителем и другими
сведениями здесь не реализована. Специфичные атрибуты каталога пока не являются
полями редактора этикеток.

## Превью и сопровождение

`manifest.json` описывает все 30 образцов, размеры, назначения, группы и
синтетические данные превью. Эти данные не копируются в шаблон: в коде остаются
переменные. PNG сняты при 203 DPI; галерея масштабирует их для просмотра.

Превью использует общий рендерер редактора и настоящий растеризатор кириллицы
и Data Matrix. Схематические линейные полосы редактора заменены в PNG настоящим
GS1-128, построенным из демонстрационного SSCC с теми же размерами.
ASCII-шрифты принтера могут отличаться от экранных. PNG не подтверждает физическое
качество печати и считывания.

Команды из корня репозитория (Node 24+, версия pnpm из `package.json`):

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm --dir tools/production-browser install --frozen-lockfile
corepack pnpm --dir tools/production-browser exec playwright install chromium
corepack pnpm turbo run build --filter='@markiro/admin^...'
node examples/labels/generate.mjs
```

В отдельном терминале запустите локальный рендерер:

```bash
corepack pnpm --filter @markiro/admin exec vite ../.. --config test/browser/vite.config.ts --host 127.0.0.1 --port 61604 --strictPort
```

Затем создайте PNG и галерею и выполните проверки:

```bash
node examples/labels/render.mjs
corepack pnpm --filter @markiro/admin exec vitest run test/label-samples.test.ts test/labels-editor.test.ts
corepack pnpm --filter @markiro/domain exec vitest run test/labels-import.test.ts
corepack pnpm exec prettier --write examples/labels/manifest.json
```

`render.mjs` дополнительно генерирует каждую этикетку в ZPL и TSPL при 203 и
300 DPI с настоящим браузерным растеризатором. Адрес рендерера можно переопределить
переменной `LABEL_SAMPLES_ORIGIN`. Исходники формируются из `generate.mjs`;
после изменения макета обновляйте исходник, PNG и галерею вместе.
Библиотека не загружается автоматически в базу и не меняет шаблоны тенантов.
