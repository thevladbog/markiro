Every contestable point found while establishing the documentation set is listed here in one place. Nothing in this file is decided. When a question is resolved, record the decision in the "Decision" column, mirror it in the owning spec, and if it changes data semantics add a review-log row in [regulatory-basis.md](regulatory-basis.md).
