# Приёмка палетных этикеток А4

Реализация находится в рабочей ветке `codex/pallet-a4-templates`.
База реализации — `aaed225880d07f6d212eb6eefb7526f32c759533`.
До commit исходник определялся полным рабочим diff, включая новые файлы;
после публикации источником является commit PR.
Перед выпуском зафиксировать итоговый SHA, версию Station и digest артефакта.
Пользователь отдельно разрешил commit/push/PR после проверок 2026-10-11.
Выпуск артефактов Station и production deploy не разрешены этим запросом.

## Автоматические доказательства

- Domain проверяет строгий V2/JSON, GS1, размеры, условные поля, даты,
  переполнение, три пресета и равенство двух копий.
- PostgreSQL/API проверяют ревизии, tenant isolation, defaults, capability,
  фактический тип устройства, сохранённый снимок смены и signed offline scope.
- Admin/Chromium проверяют редактирование, undo, JSON round-trip и одинаковые
  байты Admin/Station с настоящими встроенными шрифтами и прямоугольным WebP.
- Station/SQLite проверяют сохранение до отправки, claim перед IPC, неизвестный
  результат после restart, явный replay, новую попытку после доказанного отказа,
  сохранение истории и восстановление tombstoned bytes из собственных ресурсов.
- Browser проверяет реальный NewShift, выбор V2, приватный логотип, поля страницы
  и payload запуска. Win32 transport в browser и unit-тестах имитируется.
- Portable Cargo проверяет настоящий модуль принтера; MSVC cross-check проверяет
  его Win32 API. Host Cargo не подтверждает поведение драйвера Windows.

Полные команды, результаты и ограничения фиксируются в журнале этапов.
Пропущенные DB/external-тесты не считаются выполненными.

## Реальная Windows/принтерная проверка — не выполнена на macOS

Для каждого лазерного и струйного принтера записать модель, версию драйвера,
очередь, настройки бумаги, физический DPI, поля, SHA Station и ревизию шаблона.

1. Напечатать все три пресета: один А4 вертикально, один А4 горизонтально,
   один горизонтальный А4 с двумя одинаковыми А5. Должен выйти ровно один лист.
2. Линейкой измерить поля, модуль, высоту SSCC и длину символа. Проверить AI00,
   контрольную цифру, отсутствие обрезки и сканирование каждой копии. Обе половины
   должны сканироваться после разреза; линия не заходит в тихие зоны.
3. Проверить разные реальные поля, 300/600/1200 dpi; Letter, неодинаковые DPI осей
   и неподдерживаемое разрешение должны дать отказ до StartDoc.
4. Проверить логотипы 1:1, 4:1 и 10:1; отсутствие логотипа, даты и ЕГАИС;
   наличие полного ЕГАИС и пятистрочного наименования. Контрагент отсутствует.
5. После подготовки изменить шаблон и логотип: неизвестная попытка повторяет
   старые байты. После доказанного отказа до отправки новая попытка сохраняет
   историю и использует сохранённые факты/ресурсы с явно проверенной геометрией.
6. Проверить очередь недоступна, нет бумаги, медленный/зависший драйвер и restart
   до/после StartDoc. Исключение и timeout не означают, что лист не вышел.
   Не должно быть автоматической повторной отправки.
7. Проверить работу offline после загрузки смены/брендинга и после перезапуска.
   Другой tenant или ключ без подтверждённой цепочки восстановления запрещает
   отправку ресурсов прежнего владельца. Штатное восстановление ключа того же
   устройства разрешает повтор с прежними ресурсами и историческим владельцем.
8. Без полного брендинга, доступной геометрии драйвера или успешной отрисовки
   Start для А4 недоступен. Явный повтор preview после исправления должен
   восстановить готовность. Неизвестный результат сразу предоставляет действие
   подтверждения фактической печати; оно не отправляет лист повторно.

Результат `sent` подтверждает ответ spooler, а физическую этикетку подтверждает
оператор/сканирование. Приёмку не заменяют screenshot, CI или cross-compilation.

## Порядок выпуска и отката

Сначала совместимые миграции/API и admin, затем отдельно разрешённая Station beta.
Старые Station/ТСД получают проекцию V1; handheld не получает А4 даже со spoofed
capability. RAW ZPL/TSPL остаются доступны. Изменений Kotlin production нет;
новый релиз ТСД для этой функции не нужен. Stable требует принятую beta и
физическую проверку.

Для прекращения новых назначений очистить глобальные/категорийные defaults А4,
затем отключить V2-шаблоны. Они исчезают из picker; сохранённые смены и задания
остаются читаемыми и восстанавливаемыми. Не удалять их снимки/ресурсы и не
откатывать API на код, который не умеет читать V2-строки. Совместимая предыдущая
Station продолжает V1; смены только с А4 требуют обновлённую Windows Station.
