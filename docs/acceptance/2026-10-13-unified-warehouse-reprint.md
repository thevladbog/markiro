# Единая перепечатка — результаты проверки 13.10.2026

Один экран и один сеанс для продукции, коробов и закрытых производственных палет. До начала выбираются три шаблона. Скан печатает найденный объект без отдельного подтверждения. Код продукции и короб не преобразуются в палету. Вид шаблона палеты определяется флагом А4 назначенного принтера; настройка оборудования остаётся в настройках станции.

Новый источник V3 хранит исторические данные палеты без исходного шаблона. Новая попытка фиксирует текущий выбранный макет, профиль и байты. Восстановление неопределённой отправки использует исходную попытку. Старые V1/V2 источники, задания и очереди совместимы; они не переписываются. Дата производства и готовая дата годности не вычисляются заново по текущему каталогу.

Миграция 0191 обновляет только точно совпавшие, неизменённые стандартные А4-макеты из 0183, сохраняя их ID. Для изменённых, переименованных, отключённых и ограниченных по категории макетов создаётся отдельный обновлённый стандарт; выбранные пользователем defaults не меняются. Обновлённый стандарт содержит отступ логотипа, заголовок «ПАЛЕТА» справа, линию под товаром и подвал. Исторические снимки не изменяются.

## Автоматическая проверка

- Domain: 1157 тестов; typecheck, lint, build.
- Station: 2343 теста; typecheck, lint, build. Регрессии финального ревью проверены RED → GREEN: старое unit/box-задание без третьего выбора; ключ Windows-журнала для палеты; новый выбранный макет при явном повторе.
- API: 4953 теста в изолированном локальном PostgreSQL; 90 условных пропусков. Typecheck, lint, build. После переноса тестовой фикстуры под API повторены два новых e2e: оба прошли. Проверяются tenant/operator denial, точное совпадение исторических фактов, аудит и разрешение реальной неизвестной отправки.
- DB: 688 тестов, включая отдельные миграционные проверки; typecheck, lint, build. Изолированная тестовая база, без production-ресурсов.
- Admin: 1706 тестов; typecheck, lint, build.
- Station release: 597 контрактов.
- Форматирование и `git diff --check`.
- Предоставленный `station-mirror (3).db`: миграции применены дважды к независимой копии; integrity_check=ok, количество исторических pallet jobs сохранено. Исходный файл не изменялся; временная копия удалена.

## Браузер

Восемь Playwright-проверок Chromium на Mac: 1024×768 и 1280×800, RU/EN, выбор трёх шаблонов, ручной ввод, восстановление неизвестной отправки, предупреждение истории. Основные действия находятся в viewport; нет вложенных вертикальных скроллов у основного экрана. Список шаблонов имеет собственный скролл при длинном каталоге.

А4 использует общий производственный layout, затем экранный canvas ограничивается 800 px. Его нельзя отправить на принтер. Снятые screenshots просмотрены: лист целиком, отступ логотипа и правый заголовок присутствуют. В холодном браузерном открытии демонстрационного А4 — 245 мс; повторное открытие — 148 мс. Это Mac Chromium с bundled branding, не измерение Windows WebView. Cache ограничен шестью записями на владельца; смена digest/branding меняет ключ.

## Внешняя приёмка перед stable

- На реальном Windows-киоске пройти один сеанс: продукция → короб → палета; проверить сканирование отпечатков.
- Выбрать А4, затем в настройках назначить термопринтер и выбрать 75×120; перепечатать ту же палету. Затем вернуть А4. Проверить новый макет и неизменные SSCC, даты, количества.
- Проверить все три обновлённых А4-макета с широким логотипом компании, отсутствующим ИНН и длинным названием.
- Прервать сеть и перезапустить приложение: сохранённое задание восстанавливается, неизвестная доставка требует проверки, повторный скан не создаёт лишнюю отправку.
- Проверить смену владельца/оператора и реальную Windows-очередь.

Эти физические проверки, Windows-сборка, live deploy и новый релиз в рамках этой ветки не выполнялись. Порядок выпуска: API с V3 и миграцией 0191, затем Station beta; stable после физической приёмки.
