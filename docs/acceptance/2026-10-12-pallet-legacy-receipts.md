# Старые подтверждения отправки палет и факты этикеток

В read-only выгрузке станции обе рассматриваемые производственные палеты и смены закрыты. Для обеих палет сохранена точная Windows-отправка `sent`, но у принятых источников отсутствует `production_delivery_json`. Сервер знает состав палеты, однако не получает отдельное подтверждение отправки этикетки. Два старых факта продукции остаются pending: в сохранённых полях нет добавленного позже `qty.boxes`, поэтому текущий валидатор отклоняет их до HTTP-запроса.

Исправление восстанавливает только метаданные отправки из последней записи драйвера с совпадающими scope, SSCC, attempt ID и digest. Один SQLite UPDATE проверяет разрешённого владельца, закрытую нерасформированную палету и отсутствие существующего receipt. Исходные данные, макет, ревизия и байты не изменяются. Новая неопределённая попытка, другой digest или другой владелец исключают восстановление. Receipt отправляется существующим каналом, в том числе при обновлении статуса перепечатки; неизвестная доставка не становится подтверждённой печатью.

Чтение старых фактов добавляет пустое поле `qty.boxes`, сохраняя даты и остальные исторические значения. UUID смены в диагностике заменён номером из зеркала; без номера выводится явное отсутствие названия. При ожидании синхронизации экран объясняет блокировку шаблонов и предлагает обновление статуса. Инструкция подтвердить или закрыть исходную попытку относится только к неопределённой/неотправленной попытке на другой станции. После успешного поиска выбор шаблона и подтверждение печати доступны прежним способом.

Проверки 12 октября 2026:

- Новые регрессии сначала воспроизвели отсутствие восстановления receipt, ошибку `qty.boxes` и UUID вместо номера смены; после исправления прошли.
- Реальные строки выгрузки воспроизведены в памяти: восстановлены два receipt `sent`, оба старых факта проходят текущий контракт. Исходный файл открыт только для чтения; данные выгрузки и временный тест не включены в Git.
- Station: 177 файлов, 2322 теста прошли (`pnpm --filter @markiro/station test --maxWorkers=2`); typecheck, lint и build прошли.
- Station release contracts: 573/573. Форматирование и `git diff --check` прошли.
- Browser: 8/8 вариантов перепечатки (1024×768 и 1280×800, RU/EN, dark/light), три А4-макета, выбор и применение шаблона, подтверждение отправки и блокировка неизвестной исходной попытки. Browser typecheck прошёл. Обновлено ожидание новой инструкции без ослабления проверки блокировки. Экран диагностики 1024×768 проверен визуально.
- Независимое ревью не выявило подтверждённых замечаний. Его отдельный тестовый запуск не стартовал из-за sandbox-доступа к Vite temp; результаты автоматических проверок выше получены основным запуском.

API, domain, DB schema и Rust не менялись; их полные тесты и Cargo отдельно не запускались. CI, выпуск новой Station, установка, сканер и физический Windows-принтер — отдельные ещё не выполненные проверки этого исправления. Тестовый полный прогон сообщает существующие предупреждения jsdom Canvas и сборка — предупреждение размера чанка; ошибок нет.
