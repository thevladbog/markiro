# Проверка товаров по вкладкам

Снимки получены из настоящего интерфейса кабинета в локальном браузерном стенде.
Ответы API, товары, код ЕГАИС, срок годности и изображение упаковки — синтетические
тестовые данные. Это подтверждение поведения интерфейса, не загрузка из реального
Национального каталога и не подтверждение производственного импорта.

- `review-2-products-390-ru-dark.png`: два товара, узкий экран, тёмная тема.
- `review-5-products-390-ru-dark.png`: пять товаров, узкий экран, тёмная тема.
- `review-2-products-1280-ru-light.png`: два товара, рабочий стол, светлая тема.
- `review-5-products-1280-ru-light.png`: пять товаров, рабочий стол, светлая тема.
- `review-5-products-1280-ru-light-mapped-only.png`: включён фильтр сопоставимых
  полей; код ЕГАИС и срок годности доступны для выбора.

Сценарий `tools/production-browser/national-catalog-tests/review-tabs.spec.ts`
проверяет партии из 2, 5 и 100 товаров при ширине 390 и 1280 px. Взаимодействия
и измерения выполняются при высоте 1100 px. Только для снимков высота увеличена
до 2000 и 1600 px соответственно, чтобы показать больше содержимого товара.

Проверены переключение вкладок кнопками и клавишами Home/End, одна строка вкладок,
отсутствие горизонтального переполнения панели, две колонки значений, сохранение
выбранных полей и фото, общий фильтр полей, блокировка общей кнопки при незавершённом
выборе на другой вкладке и отправка решений для всей партии.

Компонентные тесты дополнительно проверяют обновление подготовки с новыми ID,
сохранение ручных названий и категорий, перенос только неизменившихся значений,
отказ от неоднозначного сопоставления полей и повторное подтверждение замены связи
при новой подготовке. При переключении вкладок и опросе того же снимка подтверждение
замены сохраняется. Новые ID фотографий требуют нового выбора: ответ API не содержит
достаточно данных для доказательства тождественности изображения.
