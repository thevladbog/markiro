# Палетные этикетки А4: шаблоны V2

В библиотеке этикеток тип «Палета А4» хранится отдельно от ZPL/TSPL V1.
Можно создать пустой шаблон, выбрать один из трёх пресетов, скопировать,
редактировать визуально и импортировать или экспортировать JSON.
Пресет — начальный макет; его название не переключает поведение renderer.

Готовые JSON для импорта:

- [А4 вертикальный](examples/pallet-a4-portrait.json).
- [А4 горизонтальный](examples/pallet-a4-landscape.json).
- [Две одинаковые А5 на горизонтальном А4](examples/pallet-a4-two-a5.json).

Экспорт содержит только `{name,purpose,spec}`. В нём нет tenant ID, ID записи,
ревизии, Windows-очереди, названия организации или байтов логотипа. При импорте
создаётся новая запись в текущей организации. Изменение существующего V2
проверяет ожидаемую ревизию; конфликт сохраняет черновик для копирования.

`spec.schemaVersion=2`, `kind=pallet_sheet`, `dpi=300`, `purpose=pallet`.
А4 задаётся ориентацией, полями, одной или двумя логическими копиями и линией
разреза. Две копии разрешены только на горизонтальном листе и принадлежат одной
палете. Native-задание всегда отправляет один лист с `dmCopies=1`.

Поддерживаются текст, поле, строка подпись/поле, логотип организации, линия,
рамка, отступ, stack, row и canvas. Размеры и координаты — миллиметры,
типографика — пункты, шрифты — встроенные IBM Plex Sans/Mono. Переполнение
останавливает подготовку с ID элемента; идентификаторы не обрезаются.
Условия ограничены наличием разрешённого поля; выражения и внешние URL запрещены.
JSON ограничен 256 KiB UTF-8, дерево — 200 узлами и глубиной 8.

SSCC-footer обязателен, один на логическую этикетку. Используется горизонтальный
GS1-128 с AI `(00)`, контрольной цифрой и тихими зонами. Высота полос не меньше
31,75 мм; X-модуль — целое число точек 300 dpi в диапазоне 6–11, длина символа
не больше 165,1 мм. Пресеты А4 используют 11, две А5 — 9 с разрешённым переходом
на 8 до сохранения изображения. Масштабирование «вписать в лист» запрещено.

Логотип берётся из личного кабинета, при явном отсутствии — встроенный Маркиро.
Прямоугольные изображения сохраняют пропорции; основной предел — высота.
Физическая ширина ячейки всё равно ограничена листом: renderer уменьшает слишком
широкий логотип или переносит соседнюю колонку, а не растягивает его.
Контрагент не выводится. Заголовок «ПАЛЕТА» использует одну «л».
Дата производства берётся только из явно заданной даты смены. При её отсутствии
не выводятся дата и рассчитанный срок годности; дата закрытия не подставляется.
Код ЕГАИС выводится при наличии, с сохранением ведущих нулей.

Глобальные и категорийные defaults А4 отделены от defaults V1. Назначение в смену
сохраняет полный spec, ID, ревизию и digest. Дальнейшее редактирование или
отключение записи не меняет этот снимок. Удаление используемой записи защищено
внешними ключами; это не удаление исторического снимка.

Порядок использования Station описан в [README Station](../../apps/station/README.md).
Критерии реальной печати — в [приёмке А4](../acceptance/validation-pallet-a4-printing.md).
