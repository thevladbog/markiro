# Регистрация программы для ЭВМ «Маркиро» в Роспатенте

Комплект для заявки на государственную регистрацию программы для ЭВМ по
ст. 1262 ГК РФ. База данных отдельно не регистрируется.

## Состав

| Файл                    | Назначение                                                                          |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `application.md`        | Значения полей заявления, сведения о правообладателе, технические сведения, пошлина |
| `abstract.md`           | Реферат для публикации в бюллетене Роспатента, две редакции                         |
| `deposit-manifest.json` | Отбор файлов и диапазонов строк для листинга, ограничение на число листов           |
| `build/`                | Результат сборки (не в Git): `deposit.pdf` и `deposit-summary.json`                 |

## Сборка листинга

```bash
pnpm rospatent:deposit
```

Скрипт `tools/rospatent/build-deposit.mjs` читает манифест, берёт указанные
фрагменты файлов, нумерует строки, добавляет титульный лист и оглавление и
пишет PDF со встроенным шрифтом IBM Plex Mono (кириллица в комментариях
сохраняется, текст доступен для поиска). Внешние зависимости и LibreOffice
не нужны. Для воспроизводимой сборки можно зафиксировать дату:

```bash
node tools/rospatent/build-deposit.mjs --date 2026-09-10T00:00:00Z
```

Сборка падает, если число листов превышает `maxPages` из манифеста. Тогда
нужно сузить диапазоны `lines` у крупных файлов.

Проверка инструмента:

```bash
pnpm test:rospatent
```

## Порядок подачи

1. Слить ветку в `main`, собрать листинг из `main`, чтобы коммит на титульном
   листе совпадал с состоянием релиза.
2. Проверить `build/deposit-summary.json`: список файлов, диапазоны строк,
   sha256 источников и PDF.
3. Открыть услугу «Государственная регистрация программы для ЭВМ или базы
   данных» на Госуслугах или на сайте ФИПС.
4. Заполнить заявление по `application.md`, вставить реферат из
   `abstract.md`, приложить `deposit.pdf`, подписать согласие автора.
5. Уплатить пошлину по реквизитам из формы и отправить заявку.
6. Сохранить входящий номер заявки и, после получения, свидетельство в
   закрытом хранилище. В репозиторий свидетельство не кладётся.

## Что не входит в комплект

- Персональные данные автора сверх опубликованных в правовых документах
  продукта: дата рождения, паспорт, ИНН.
- Согласие на указание сведений об авторе и на обработку персональных данных:
  формируются и подписываются в форме подачи.
- Квитанция об уплате пошлины.
