# Реферат программы для ЭВМ «Маркиро»

Реферат публикуется Роспатентом в официальном бюллетене. Ниже основная
редакция для поля «Реферат» электронного заявления и запасная короткая
редакция на случай, если форма ограничит объём.

## Основная редакция

Программа «Маркиро» предназначена для организации производственных процессов
с обязательной маркировкой товаров в системе «Честный знак». Область
применения: производственные предприятия и склады, работающие с ГИС МТ.
Функциональные возможности: проверка контрольных цифр GS1 и разбор кодов
маркировки с отклонением дубликатов и кодов чужого GTIN; ведение
производственных смен с несколькими терминалами; автономная работа линейной
станции с локальным журналом и последующей синхронизацией с сервером;
агрегация продукции в короба с пулами SSCC и печать этикеток ZPL/TSPL по
шаблонам; задания инвентаризации, пересчёт, переупаковка и формирование
документов ГИС МТ; киоск выдачи продукции сотрудникам с offline-очередью;
агент подписания для аутентификации в True API; мультитенантный кабинет с
ролями, аудитом, биллингом, API и обменом CommerceML/1C. Тип ЭВМ:
IBM PC-совместимые ПК, серверы x86-64, Android-терминалы. ОС: Windows 10/11,
Linux, macOS, Android 8+. Языки: TypeScript, Rust, Kotlin, SQL. Объём
исходного текста: 13 МБ.

## Короткая редакция

Программа «Маркиро» предназначена для производственных процессов с
маркировкой товаров в системе «Честный знак»: проверка и учёт кодов
маркировки GS1, ведение смен, автономная работа линейной станции с
синхронизацией, агрегация в короба (SSCC), печать этикеток ZPL/TSPL,
инвентаризация с формированием документов ГИС МТ, киоск выдачи продукции,
агент подписания для True API, мультитенантный кабинет с API и обменом
CommerceML/1C. Тип ЭВМ: IBM PC-совместимые ПК, серверы x86-64,
Android-терминалы. ОС: Windows, Linux, macOS, Android. Языки: TypeScript,
Rust, Kotlin, SQL. Объём: 13 МБ.
