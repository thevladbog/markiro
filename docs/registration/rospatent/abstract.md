# Реферат программы для ЭВМ «Маркиро»

Реферат публикуется Роспатентом в официальном бюллетене. Поле «Реферат»
электронного заявления принимает не более 900 знаков, сборка `abstract.pdf`
проверяет этот лимит для основной редакции. Короткая редакция запасная, на
случай если форма потребует ещё меньший объём.

## Основная редакция

Программа «Маркиро» предназначена для организации производственных процессов
с обязательной маркировкой товаров в системе «Честный знак». Область
применения: производственные предприятия и склады, работающие с ГИС МТ.
Функциональные возможности: проверка контрольных цифр GS1 и разбор кодов
маркировки с отклонением дубликатов и чужих GTIN; ведение смен с несколькими
терминалами; автономная работа линейной станции с локальным журналом и
синхронизацией с сервером; агрегация в короба с пулами SSCC и печать
этикеток ZPL/TSPL; инвентаризация с формированием документов ГИС МТ; киоск
выдачи продукции с offline-очередью; агент подписания для True API;
мультитенантный кабинет с ролями, аудитом, API и обменом CommerceML/1C. Тип
ЭВМ: IBM PC-совместимые ПК, серверы x86-64, Android-терминалы. ОС: Windows
10/11, Linux, macOS, Android 8+. Языки: TypeScript, Rust, Kotlin, SQL.
Объём: 13 МБ.

## Короткая редакция

Программа «Маркиро» предназначена для производственных процессов с
маркировкой товаров в системе «Честный знак»: проверка и учёт кодов
маркировки GS1, ведение смен, автономная работа линейной станции с
синхронизацией, агрегация в короба (SSCC), печать этикеток ZPL/TSPL,
инвентаризация с формированием документов ГИС МТ, киоск выдачи продукции,
агент подписания для True API, мультитенантный кабинет с API и обменом
CommerceML/1C. Тип ЭВМ: IBM PC-совместимые ПК, серверы x86-64,
Android-терминалы. ОС: Windows, Linux, macOS, Android. Языки: TypeScript,
Rust, Kotlin, SQL. Объём: 13 МБ.
