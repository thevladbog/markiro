Полные прогоны ниже относятся к исходной базе `0579c5ff3`. После переноса на
`aa4804d33` повторены 84/84 теста входящих изменений main, 61/61 защитная
проверка, 32/32 TSPL, 586/586 production bundle contracts, frozen install,
`check:deps`, `format:check` и `git diff --check`. Полные JS/Cargo-прогоны после
rebase не повторялись.

- До патча deepmerge падали 4 регрессионных теста CJS/UMD; после патча — 4/4.

  после исправления файл импорта — 32/32. Дополнительно 50 000 детерминированных
  сравнений старого/нового разбора коротких строк не выявили различий.

- Чистый frozen install основного workspace: пройден, 1575 установленных пакетов.

- Локальный Chrome: запуск, страница и чтение DOM прошли через CDP и WebDriver BiDi.
- Сам Lighthouse `13.5.0` завершил SEO-аудит локальной тестовой страницы с
  обновлённым Puppeteer без runtime error. Это smoke-тест, не оценка production SEO.
- Изолированный mail pipeline: 2/2 на свежей одноразовой PostgreSQL.

Причины пропусков: DB 7 и API 27 требуют отдельного release-catalog кластера;
API 4 — отдельного platform-profile кластера; API 3 — Mailpit/S3 smoke-окружения;
API 1 — live National Catalog; API 1 — управляющего browser-harness. У standalone
два browser-fit теста требуют отдельного браузерного запуска, ещё один —
`STANDALONE_HISTORY_ACCEPTANCE_OUT` от PostgreSQL/Rust seam. Десять тестов
saas-admin отключены штатным флагом support chat. Эти поверхности не выдаются
за проверенные текущим прогоном. Двенадцать Rust `ignored` — отдельный
PostgreSQL-to-host seam, ручной миллионный benchmark, live Yandex OAuth-сценарий
и девять сценариев запуска/остановки/нагрузки собственного host, для которых
исходники требуют отдельного доверенного запуска с `--ignored`.

Архивные результаты не подменяют текущие проверки. Архивный полный DB-прогон
содержит падение mail-pipeline: ожидалось 1, получено 26. Сам тест использует
общий outbox без изолированной базы, что допускает зависимость от порядка файлов.
В текущих изолированном и полном прогонах он прошёл. Тест не менялся; прохождение
текущего прогона не означает, что историческая нестабильность исправлена.

Не выполнялись: production, Windows, WebView2, физические принтеры/сканеры,
реальная UKEP/CryptoAPI/DPAPI, mail/1C/Chestny ZNAK, реальный Yandex Disk или
установка обновления через Tauri. Локальный Chrome не подтверждает production.
Результатов удалённых CI и CodeQL для публикуемой ветки на момент локального
аудита нет; их следует оценивать отдельно по проверкам PR.

в полученном снимке нет.
