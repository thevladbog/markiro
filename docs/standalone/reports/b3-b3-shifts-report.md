# b3-shifts: карточка смены как боковая штора над «Смены»

Ветка `claude/b3-shifts` (worktree `/tmp/claude/wt/b3-shifts`), основа — `claude/integration` (влит `f24a75625`).

## Что сказал владелец

«Непонятно, как после закрытия смены будет открываться информация по ней. В облаке всё сделано через боковые шторы, это удобнее и для статистики, и для отчётов.»

## Что было не так

Смена открывалась отдельной страницей `/shifts/:id` (`ShiftCardPage`) с длинной простынёй секций: список терялся, закрытую смену читали «с нуля» (все секции грузились сразу), итоги были отдельным модальным окном, истории выгрузок не было.

## Что сделано

1. **Штора** (`SidePanel` из `@markiro/ui`, размер `complex`, ширина `min(960px, 92vw)`, на окне ≤1100 px — во всю ширину). Страница списка остаётся под ней с фильтрами, сортировкой и страницей. Адрес `/shifts?shift=<id>[&tab=<вкладка>][&box=<хвост SSCC>]`. Старый `/shifts/:id` перенаправляет на него (`ShiftCardRedirect`, `?box=`/`?tab=` сохраняются). Все ссылки на смену (конфликты, поиск кодов, листы A4, дезагрегация) теперь ведут на адрес шторы (`shiftCardPath`).
2. **Шапка шторы**: номер, статус и отметки (данные после закрытия, причина закрытия), действия «Выгрузка», «Закрыть» (planShifts, активная), «Бланк смены», «Ярлыки паллет смены» — прямо из шторы, диалоги открываются поверх (стек `OverlayLayer`, Esc закрывает верхний слой).
3. **Вкладки** (`DataTabs`, стрелки/Home/End): Итоги (сведения + «Контроль печати» + цифры смены и устройства — вынесено из `ShiftTotalsDialog` в `ShiftTotalsBody`, диалог в списке остался), Короба (ссылки на карточки коробов/паллет плана КРТ, фильтр по хвосту SSCC, «Состав»), Паллеты (Состав/Ярлык), Исключения (в т. ч. дезагрегации-документы со ссылками), Отклонённые записи, Конфликты (КНФ), **Выгрузки** — новая история выгрузок. У запланированной смены вкладок нет, только сведения; у проверочной нет Коробов/Паллет/Исключений. Каждая вкладка читает данные только при первом открытии; есть состояния загрузки, пусто, ошибка с «Повторить». Логика секций не переписывалась — перенесена как есть (`ShiftDrawer.tsx` = бывший `ShiftCardPage.tsx`).
4. **История выгрузок**: новый маршрут хоста `GET /v1/office/shifts/{id}/exports` (читает аудит `shift.export`, новые сверху, не более 50, имя пользователя), миграция `0027_audit_target_index.sql` (индекс `audit_log(target_id, action, at)` — без него чтение шло по всему аудиту), proto `OfficeShiftExports`, Zod, фикстура `office-shift-exports.json`, запись в `license/gate.rs` NEVER. Показывает: когда, формат (человеческое имя из домена), число кодов/коробов/паллет/частей, «Паллеты»/лимит строк, кто.
5. **Список для статистики**: сортируемые колонки (номер, дата, линия, товар, план, статус, выпуск; клик или Enter/Space, `aria-sort`), строка «Итого по выбранным сменам: смен · выпуск · коробов · паллет» по всему отфильтрованному набору (не по странице), открытие шторы кликом по любой ячейке строки (ссылки/кнопки внутри строки работают сами по себе).
6. `@markiro/ui` `Table`: заголовок сортируемой колонки фокусируется и работает с клавиатуры, `aria-sort`; клик по контролу внутри кликабельной строки не вызывает `onRowClick` (затронет и другие `Table` с `onRowClick`; тесты пакета зелёные).

Клавиатура/фокус: Esc закрывает шторы, фокус возвращается на ссылку-номер в строке (проверено в браузере и тестом). Вложенные поповеры не закрывают штору (механизм `data-mk-nested-overlay` в `OverlayLayer`).

## Не проверено / ограничения

- WebView2/Windows, реальный хост (проверено на фейковом API в браузере-стенде Vite + cargo-тесты хоста).
- Нет данных «по операторам» (в `OfficeShift.totals` только устройства): итоги по операторам не сделаны, нужна отдельная правка хоста.
- Отдельной вкладки «Дезагрегации» нет: документы дезагрегации смены уже показаны в «Исключениях» со ссылками на документ.
- «Скачать файлы ЧЗ» из истории нельзя: хост хранит только запись об экспорте, файлы лежат в папке `Документы\Markiro\Выгрузки`; повторная выгрузка — кнопка «Выгрузка».
- Таблица списка при окне 1280 уже горизонтально скроллится (было до правок).
- Дата смены (агент b3-stats): не делалась; пересечения файлов — `ShiftsPage.tsx`, `shift-list.ts`, `shift-card.ts`, `ShiftDrawer.tsx` (бывш. `ShiftCardPage.tsx`: переименование — конфликт git вероятен, лучше решать переносом правок), `ru.json`, `test/shifts-page.test.tsx`, `test/shift-card.test.tsx`.
