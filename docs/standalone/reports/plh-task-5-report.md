## Self-review and concerns

1. Behaviour pinned that the brief left open: a pallet label check of a disassembled pallet is accepted (brief), a label check may be sent again with a later instant and overwrites the earlier mark of the same outcome (brief test 305); a `verified` and a `skipped` mark can both be set on one pallet (as for boxes). Not pinned by design: `reasonCode: "other"` with no words is accepted (`(_, None) => Ok(None)`), same as `box_exception`; the spec is silent. If the owner wants words required for `other`, it is a one-line change for both kinds plus fixtures.
2. A pallet exception does not check the pallet has boxes, or that `occurredAt` is not before the pallet's `closedAt`; consistent with Task 4's "evidence, not guards".
