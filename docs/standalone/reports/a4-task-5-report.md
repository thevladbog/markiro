- `src/office/sheets/PalletSheetsPage.tsx`, `sheet-list.ts`, `SheetPreview.tsx`: the page «Листы А4» (`/pallet-sheets`, menu item in «Каталог» for both roles, `editCatalog`). Stock sheets (idempotent by key, partial failure keeps what was added and reads the list again), JSON load (strict domain reading; 256 KiB file bound checked before reading; wrong purpose/label template/bare spec/broken file refused with a precise text; name trimmed; always a new sheet, no preset key), JSON save (`sheetFileName` strips characters a file name cannot hold), rename (trimmed, same/blank name keeps «Сохранить» off), on/off with `expectedRevision`, main sheet, delete behind a destructive confirmation. Preview in a `Modal`: `SheetPreview` draws once per sheet (spec parsed when the dialog opens), supersedes a slow draw, says so when the draw fails, when the organization/logo did not load, and while loading.
- Duplicate names (addendum): the host keeps names non-unique, so the page warns, in words and not by colour (a `StatusChip phase="duplicate"` «Название повторяется» on each such row + one warn Alert above the table), the rename dialog warns live (still saves), and the shift's choice tells same-named sheets apart by the first 8 characters of the id.
- Shift dialog (`ShiftDialog.tsx`, `shift-form.ts`, `shifts/sheet-options.ts`): «Лист А4» select below the pallet template, only with pallets (the sheets are read only then). First choice «Основной лист организации (…)» (`""`, sends nothing) — offered only to a shift that holds no sheet (a new one, or a planned one without): `ShiftUpdate.palletSheetTemplateId` cannot be `null`, so «main» would be silently ignored for a shift that holds one. A sheet the host refused (`validation_failed` on `palletSheetTemplateId`) goes under the select, takes the focus and the sheets are read again; the refusal is dropped when pallets are turned off (it is not cleared by a product change: the sheet does not depend on the product). The list failing to load says so and the shift is still saved (host takes the main sheet / keeps its own).
