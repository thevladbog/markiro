## Self-review (the lessons list)

- Boundary `nextSerial == maxSerial` vs `> maxSerial`: both sides in the page test, plus a unit on another bound (m1, m6, m7).
- Detail key `similarLogin`: equal / differs / absent / null / non-text / other constraint / other code all pinned, on the page and in a unit (m3, m8-m11).
- Warning trigger: active shift of THIS station only; planned (even with an owner), closed, other station's: no; moving vs not moving; moving to the own line again clears it (m4, m5, m18-m20).
- Role gating: «Устройства» is administrator-only (existing test); the exhausted tag also shows for the technologist, who has no edit column.
- Earlier behaviour kept: the stale-state handling, all-controls lock and the `FormDialog` flow are unchanged (no dialog logic changed besides the added branch); focus convention added (see adaptations).
- Swallowed-refusal class: the similar refusal is a field error on a field with a control, with `aria-describedby` and focus; the only silent path is the intended one (shifts not loaded: no warning, see concern 1).
- Tests free of the effect race: `act`-wrapped focus, positive control before every absence assertion that depends on the shifts landing; delayed-`setImmediate` run clean.

## Concerns

1. A shifts list that fails to load gives no warning and no hint (as the brief says), so an administrator can move a station that has an active shift without being told; an inline note "the list of shifts did not load, check the station's shift on «Смены»" would be a small, separate decision for the owner.
2. The warning is based on the list read when the dialog opens (and the cached one is shown first, until the re-read lands); a shift opened or closed meanwhile is not reflected. The host does not refuse the move either way (В9 A), so it only informs.
3. Choosing «Не выбрана» (no line) for a station with an active shift shows the same text, "покажет смены новой линии", which is not accurate for no line; plan text kept letter for letter.
4. The `similar` state in `CreateOperatorDialog` is not cleared when a later refusal is of another kind; it is only used when the message key has `{{similar}}`, so it is harmless.
5. Counts: my totals differ from the plan's because the branch base carries Task 4-6 extras (2006 vs 1869 in the plan; 78 vs 63 in the three files).
