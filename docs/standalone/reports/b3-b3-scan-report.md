# b3-scan: проверка сканера на станции («Проверить сканер»)

Ветка `claude/b3-scan` (от `claude/integration` 630d211cf), worktree `/tmp/claude/wt/b3-scan`.

## Что просил владелец

«для сканеров также нужна возможность проверки, что сканирует ок. Желательно datamatrix с GS символом».
Уточнение координатора: сделать как в облачной станции (станция сама показывает код, оператор
сканирует, станция сверяет скан с тем, что показала), и расширить: DataMatrix с настоящими GS.

## Что было не так

Блок «Проверка сканера» (fb-station) на экране подключения только говорил ВИД скана (длина, есть ли GS,
русская раскладка) и ничего не сверял: у станции не было эталона. Облачная станция
(`apps/station/src/ui/setup/ScannerSetupPanel.tsx`, `test-code.ts`) показывает случайный `MKR-XXXXXX`
Code 128, сверяет скан строго `===` и пишет «Код совпал — сканер работает корректно» / «Получен другой код».
В автономе этого не было совсем; проверки DataMatrix/GS не было нигде.

## Что сделано

Панель «Проверить сканер» на вкладке «Рабочее место» → «Сканер» и на экране настроек сканера до
подключения (scope `scanners`). Станция генерирует свежий тестовый код при каждом открытии, смене вида и
«Новый код», показывает его, сверяет скан с ним символ в символ и объясняет РАЗЛИЧИЕ.

- Два вида кода, как просил координатор: «Простой код» (тот же `MKR-XXXXXX` Code 128, что в облаке) и
  «DataMatrix с GS» (по умолчанию): `01<тестовый GTIN>21TEST<серийный>␝91TEST␝92TEST<хвост>`, настоящие
  `\u001d`. Тестовый GTIN `0299999999999`+контрольная цифра (диапазон 02: «ограниченное обращение», ни
  одному производителю не выдаётся, на экране и в PDF подпись «ТЕСТ»). Символ рисует доменный
  `renderDataMatrixSvg` (FNC1-обрамление, как на этикетках продукции), код-128 для простого вида.
- Вердикт: ОК / ВНИМАНИЕ / ПРОБЛЕМА (глиф и слово, не только цвет) + причина по-русски с подсказкой, что
  настроить: совпало; префикс символики (`]d2`, предупреждение: станция его снимает); искажённые байты
  (скорость COM); GS потерян; GS пришёл другим символом/последовательностью (`|`, `<GS>`, управляющий
  код, называется найденное); русская раскладка (через `fromRussianLayout`); обрыв (где); потеряно начало;
  лишние символы (CR/суффикс); отличие (позиция, ожидалось/пришло); чужой код. Рядом: канал
  (клавиатура/COM), длина «N из M», GS «пришло k из m», как станция читает скан (КМ/SSCC/GTIN/неопознан —
  через `classifyScan` из `@markiro/domain`, без переписывания), структура AI (01 с проверкой контрольной
  цифры, 21, 91, 92…) с длинами, но без значений.
- Приватность: скан показывается только маской (первые/последние символы, остальное «•», каждый GS виден
  как «␝»). Подробное «ожидали/пришло» показывается только для кода, близкого к тестовому; чужой скан
  (бейдж) называется «чужой код» и не показывается. Текст скана нигде не пишется в лог. История —
  последние 5 проверок в сессии экрана настроек (хук держится в `WorkstationSetup`, переживает смену
  вкладки, не хранится на диске).
- Тестовый код: «Показать на экране» (полноэкранное окно `FullScreenDialog`, крупный символ, вердикт тут же),
  «Скачать PNG», «Скачать PDF» (одностраничный векторный A5, слово TEST, код словами с `<GS>`), «Печать»
  (на выбранный этикеточный принтер через `render(spec, data, printer)` и `printing.send`; DataMatrix
  идёт через штатный `km.code` с GS1-обрамлением: в ZPL `^BXN…^FD_1…_1D91TEST_1D92TEST`; A4-принтеры
  не предлагаются). Станция не принимает тестовый код как продукционный: он обрабатывается только в этой
  панели (setup-экран не слушает пайплайн смены; GTIN диапазона 02 нет в каталоге и отвергся бы).
- Канал скана: `ScanSource` получил необязательный `startTagged` (клавиатура → `keyboard`, COM → `com`,
  `mergeScanSources` пробрасывает, источник без метода → `unknown`); `start` не менялся, старые тесты и
  моки целы.
- Видимый эффект экрана настроек: на вкладке «Сканер» теперь блок «Проверить сканер» ниже карточек
  подключения; на вкладках «Принтеры» сканы пробной этикетки в историю самотеста не попадают.

## Что НЕ проверено

- Реальный сканер (HID-клавиатурный и COM): как он на деле отдаёт GS, `]d2`, раскладку; Windows/WebView2.
- Читается ли показанный на мониторе/сенсорной панели DataMatrix реальным сканером (размер модуля,
  блики, яркость); печать реальной этикетки на принтере; открытие PNG/PDF в WebView2 (`<a download>`).
- Генерация PNG (canvas) не покрыта автотестом (в jsdom нет canvas); PDF проверен структурно.
- Визуально проверено в браузере (Chrome-панель, harness с фикстурами вне репозитория, 1280×1024): панель,
  вердикты ОК/ПРОБЛЕМА/ВНИМАНИЕ, окно «Показать на экране». Скриншоты хранит лог сессии, отдельные файлы
  в `/tmp/claude/fb/b3-b3-scan/` не сохранялись (инструмент не пишет на диск).

## Вопросы владельцу

1. Префикс `]d2` оставил предупреждением (станция его снимает), а не ошибкой. Если нужно строго, поменять
   статус на «ПРОБЛЕМА» в `judgeScan`.
2. После «ОК» код не обновляется сам (как в облаке): для следующей проверки нажать «Новый код».
