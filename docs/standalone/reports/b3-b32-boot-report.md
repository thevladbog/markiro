# b32-boot: стартовый экран по роли ПК

Ветка claude/b32-boot (от claude/integration), worktree /tmp/claude/wt/b32-boot.

## Что просил владелец

Хост поставили: при запуске сразу Офис. Станция: вход в Станцию. Отдельный офис: вход в Офис.

## Что было

Роль уже читалась (`install_role`), но только офисная роль уходила со станционных экранов; ПК хоста стартовал на «Вход оператора» с кнопкой «Офис».

## Что сделано

- `src/app/start-screen.ts` (новый): чистая функция `startView(shellView, role, hostHome)` и `INITIAL_HOST_HOME = "office"`.
- `src/app/App.tsx`: вместо встроенной проверки роли office используется `startView`; состояние `hostHome` только в памяти страницы (не хранится: после перезапуска хост снова в офисе); `openOffice` (кнопка «Офис» цеха и выбора линии) и `openFloor` («В цех» на «Вход в офис») переключают его; у роли host шапка офиса говорит «Выйти» и возвращает на «Вход в офис» (`exitTo: "sign_in"`).
- Пока роль неизвестна, экран цеха не рисуется (`loading`): иначе хост на миг показал бы «Вход оператора».
- Мастер первого запуска (bootstrap) и экраны подключения не затронуты, они идут раньше.
- Политика окна не менялась (таблица в AGENTS.md).

## Таблица: роль x состояние -> первый экран

| Роль                     | Состояние                | Первый экран                                                                                                |
| ------------------------ | ------------------------ | ----------------------------------------------------------------------------------------------------------- |
| host                     | хост не инициализирован  | мастер первого запуска («Первый запуск»)                                                                    |
| host                     | хост готов, ПК не спарен | автоматическое спаривание, затем вход в офис                                                                |
| host                     | спарен, любой запуск     | «Вход в офис» (есть «В цех»); после «В цех» вход оператора, «Офис» возвращает; после перезапуска снова офис |
| host                     | выход из офиса           | «Вход в офис»                                                                                               |
| office                   | не подключён к хосту     | экран подключения (host_missing / «Подключиться к хосту в сети»)                                            |
| office                   | подключён                | «Вход в офис», без «В цех»; цеха и выбора линии нет никогда                                                 |
| station                  | не подключён             | «Служба хоста не отвечает» / подключение к хосту в сети, обычное окно                                       |
| station                  | спарен, без линии        | «Выбор линии» (обычное окно)                                                                                |
| station                  | настроена                | вход оператора (киоск); офис сам не открывается                                                             |
| нет роли / ошибка чтения | как station              | как station                                                                                                 |
| любая                    | роль ещё не получена     | загрузка (цеха не видно)                                                                                    |

Станция и офис: «Офис» на входе оператора у станции оставлен. Это задокументированный путь: AGENTS.md (оконная политика) описывает офисную сессию администратора на настроенной станции (обычное окно, «Оконный режим»). Намеренно, абзац в AGENTS.md добавлен.
