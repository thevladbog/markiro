## Отклонения

Подробно — в разделе «Отклонения при исполнении» плана. Главное: `okhttp-tls` нет в офлайн-кэше, тестовые сертификаты — через `keytool` (`TestTls`); формат фактов по `facts-request.json`, а не по черновику плана; облачный `SyncEngine.drainAll` получил одну строку раннего возврата для `backend == host`; `HostLinkState` (С5) и `HostLinkStatus` (Д4) — разные типы; пульс и обход адресов, не назначенные планом никому, сделаны в Д4.
