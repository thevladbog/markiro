# Автоном · Офис — реализация дизайна v0.3

Отчёт фиксирует проверку реализации перед публикацией PR. Ветка `codex/autonom-office-design`, база `5e6794ba7`.

[Галерея скриншотов](index.html) · [Измерения Chromium](measurements.json)

## Что изменено

- Общие компоненты `packages/ui`: векторные значки, красная кнопка закрытия с целью 44 px, центрирование иконки алерта относительно всего блока текста, оптическое выравнивание подписей и состояния нажатия Kit 2026. Цеховые кнопки сохраняют прежнюю структуру дочерних элементов и размеры.
- `apps/standalone/src/office/shifts`: сводка выпуска с планом, самостоятельные проверки упаковки и частей смены, вклад устройств, раскрываемые параметры. Девять вкладок, прежний диалог итогов и действия сохранены.
- Палеты: компактные действия 88×36 в одной строке. История сканирований: согласованная сетка фильтров и пять колонок с двухстрочными ячейками. Сохраняются оператор, часовой пояс, маскированные хвосты кода и обе ссылки на упаковку.
- Настройка сканера: один заголовок, две колонки, офисные контролы 44 px, тестовый код, ясный результат. Печать, PNG/PDF, обновление кода, история и подробная диагностика доступны через «Дополнительно».

## Проверки

- Общий UI: 345 тестов прошли.
- Автоном: 8 892 теста прошли, 4 браузерных теста штатно пропущены без `PLAYWRIGHT_CORE`. Отдельно выполнена браузерная проверка ниже. Повторный полный прогон после ревью завершился с тем же результатом.
- Целевые сценарии после исправлений ревью: 94 теста прошли.
- Проверки типов admin, kiosk, station и saas-admin: 8 задач Turbo прошли (включая сборки общих зависимостей).
- `ui` и `standalone`: typecheck, lint и build прошли. Сборка Vite сообщает о чанках крупнее 500 КБ; ошибки сборки нет.
- `pnpm format:check` и `git diff --check` прошли.
- `cargo test --manifest-path apps/standalone/Cargo.toml --workspace --offline`: 2 830 тестов прошли, 12 штатно пропущены, ошибок нет. Пропуски: отдельная PostgreSQL-база, миллион сканов, живой Yandex OAuth и сценарии запуска/остановки хоста и нагрузки, требующие явного запуска.

## Браузерная проверка

Скриншоты сняты с действующего интерфейса Chromium, а не с макетов. Стенд использует настоящие компоненты Office и синтетический Host API из `apps/standalone/test/harness/office-review/`. COM и локальное хранилище имитируются. Полное совпадение тестового кода и потеря GS проверены через существующий обработчик сканирования.

| Проверка                               | Результат                                                                   |
| -------------------------------------- | --------------------------------------------------------------------------- |
| Светлая и тёмная темы, 1280×800        | Сводка, палеты, сканирования, сканер: ожидание, успех, потеря GS            |
| Кнопки шапки                           | Одна линия, высота 44 px                                                    |
| Действия палет                         | По 88×36 px, центры совпадают                                               |
| Вторая строка фильтров                 | Поля и кнопка на y=361, высота 44 px                                        |
| Иконка и полный текст алерта           | Разница вертикальных центров 0 px                                           |
| Окно сканера                           | 976×704 px при 1280×800                                                     |
| Высота 720 px, ширины 1280 / 640 / 390 | Footer виден, кнопки внутри окна, страница без горизонтального переполнения |
| Ошибка сохранения, 390×720             | Текст ошибки остаётся видимым, кнопки доступны                              |
| Карточка смены, 390×720                | Занимает ширину окна, нет переполнения страницы и тела drawer               |

Для просмотра: `pnpm --filter @markiro/standalone dev --host 127.0.0.1 --port 5377`, затем `/test/harness/office-review/index.html?path=%2Fshifts&scenario=shift&theme=dark`. Для ошибки сохранения добавьте `&scannerSave=fail`. Никакие запросы к реальному хосту этот стенд не выполняет.

## Решения и ревью

- Ревью выполнено по рабочим файлам относительно базы `5e6794ba7`. Проверенные исходники зафиксированы по SHA-256 в [манифесте исходников](source-manifest.sha256).
- Расширенные операции сканера сохранены в раскрываемом разделе: для них нужен дополнительный клик.
- Независимое ревью выявило скрытый статус сохранения на узком окне и нарушение дочерней структуры цеховых кнопок. Оба дефекта воспроизведены до исправления, затем проверены. Подпись закрытия приведена к «Закрыть настройки сканера».

Физический сканер, принтер, Windows/WebView2 и реальный Host API не проверялись. Проверка хостового Rust workspace на macOS не доказывает работу этих сред. Локального графа Graphify в изолированном worktree нет; граф исходного рабочего каталога не менялся.
