# README visual assets

The four existing SVG logo variants are the canonical Markiro wordmarks.
They are reused without a redesign. Light/dark variants follow the reader's
GitHub color scheme.

## Workbench cover

- File: `standalone-workbench.jpg`.
- Generated on 2026-10-18 with the built-in image generation tool.
- A generated editorial illustration, not evidence of a customer installation.
- Stored as JPEG for a small README download; the scene has not been retouched.

Prompt: Wide editorial industrial photograph of a compact factory packing
workbench, approximately 3:1. A thermal label printer, barcode scanner in its
stand, plain labelled cartons, the edge of a pallet and one local computer
connected by practical cables. Monitor from the back, with no UI visible.
Neutral painted wall, steel surface, graphite devices, tiny functional green
scanner light, soft daylight. No people, text, logos, fake dashboards, cloud
symbols, diagram overlays or watermark. Understated working factory, not a
futuristic showroom.
