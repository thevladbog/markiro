# Маркиро — фирменные бланки

Комплект бланков для деловой документации (письма, договоры, соглашения).
Строится на утверждённой айдентике «Прибор»: инженерный монохром, единственный
акцент — зелёный модуль знака, IBM Plex Sans + IBM Plex Mono
(см. `docs/design-briefs/design_handoff_markiro/design-system/`).

## Состав

| Файл                         | Что это                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `markiro-blank.docx`         | Рабочий шаблон Word: первая страница с полной шапкой, последующие — с компактной, подвал с реквизитами и нумерацией |
| `make-letterhead.js`         | Скрипт генерации .docx (`node docs/brand/letterhead/make-letterhead.js` из корня репозитория)                       |
| `exports/markiro-blanki.pdf` | PDF всех трёх макетов                                                                                               |
| `exports/*.png`              | Превью макетов                                                                                                      |
| `assets/lockup*.png`         | Логотип-локап для вставки в документы (2x)                                                                          |

## Правила бланка

- **Формат:** A4. Поля: слева 20 мм (подшивка), справа 15 мм, сверху/снизу 15 мм.
- **Шапка (стр. 1):** знак 42 px + словознак «маркиро» (IBM Plex Mono 600),
  справа — markiro.app и hello@v-b.tech. Под шапкой линейка с зелёным
  модулем `#0FAF56` у левого края.
- **Шапка (стр. 2+):** компактный знак 24 px, тонкая линейка — документ
  узнаваем, место не тратится.
- **Текст:** IBM Plex Sans 11 pt, интервал 1,5, выравнивание по левому краю
  (в договорах преамбула — по ширине). Числа, номера КМ, идентификаторы —
  IBM Plex Mono.
- **Цвета:** чернила `#17161A`, вторичный текст `#45433E`, служебный `#6B6862`,
  линии `#E0DED7`/`#C9C6BD`. Никаких других цветов на бланке.
- **Подвал:** hairline-линия; реквизиты оператора из
  `packages/legal-documents/src/operator.ts` (Богатырев В. С., телефон, почта,
  адрес); справа — номер страницы `стр. N` (IBM Plex Mono). Data Matrix,
  код и редакция шаблона на бланк не ставятся — это атрибуты конкретных
  опубликованных документов реестра, а не пустого шаблона.

## Связь с канонической системой

Бланки следуют опубликованному шаблону MKR-BRD-01 (`/legal/brand-letterhead/`
на лендинге, редакция 2026.08/01 от 15.08.2026). При смене профиля оператора
обновить константы `OPERATOR_*` в `make-letterhead.js` и повторно проверить
сгенерированные DOCX/PDF.

Шрифты IBM Plex Sans / IBM Plex Mono должны быть установлены на машине,
где открывается .docx (бесплатно: <https://github.com/IBM/plex>). Без них
Word подставит системную замену.
