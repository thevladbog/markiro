# Создание смены с ТСД в «Автономе»

Оператор на мобильной линии создаёт смену без обращения в офис. Сценарий согласован по макетам OpenPencil.

1. Хост отдаёт ТСД справочники для формы и создаёт смену на назначенной линии по действующим правилам лицензии, товаров и шаблонов. Проверяет, что линия не изменилась с момента заполнения. Использует общий помесячный счётчик; номер ТСД оканчивается на `/M`. Проверить все три режима, доступ, повтор запроса и отображение номера в офисе.
2. ТСД показывает «Новая смена» на совместимом хосте. Оператор сканирует товар или ищет его по имени, выбирает режим, даты смены и производства, при желании вводит план. Поля коробов и паллет появляются по режиму.
3. ТСД сохраняет черновик и перед отправкой фиксирует запрос. При потерянном ответе повторяет тот же запрос; после получения номера открывает именно созданную смену обычным маршрутом. Проверить разбор сканов, поля всех режимов, границы плана, обработку повтора и Android сборку.
