# Проверка доработок печати Station

Ветка: `codex/station-printing-follow-up`; база `a83850543`. Изменения не опубликованы на станции и не развёрнуты в production.

## Выполненное поведение

- Дата производства и исторический срок годности единицы сохраняются вместе с принятым сканом. Закрытие смены и изменение каталога не меняют эти поля. Старые данные используются только при доказанной связи с исходным заданием или закрытым коробом; неизвестный исторический срок не вычисляется из сегодняшнего каталога.
- Три новых пресета А4 имеют отступ между логотипом и организацией, заголовок «ПАЛЕТА» справа, подчёркивание продукции и футер ИНН/Маркиро. Для применения создаётся новый шаблон и назначается новой смене. Пользовательские шаблоны, открытые смены и сохранённые задания не переписываются.
- Термоэтикетка и А4 выбираются в общей форме профиля и сохраняются одним существующим атомарным PUT. Категории берутся из каталога; сохранённые назначения отсутствующих категорий показаны явно. Русские названия tenant admin используют «палета».
- Отдельный режим перепечатки находит закрытую производственную палету Station по её SSCC, коробу или полному коду продукции. Поиск и отмена не отправляют печать. Подтверждение создаёт собственное задание с сохранёнными полями, шаблоном и ресурсами. Состав связывается точными хешами и временем принятия единиц, а не только количеством.
- После ошибки до отправки возможна явная попытка с новым профилем. При неопределённой доставке повтор сохраняет байты и геометрию. Проверка/пропуск разрешают только собственные попытки перепечатки; исходная производственная попытка остаётся отдельной.
- Источники и аудит синхронизируются после производственного outbox. Снимок закрытия сохраняется до проверки принтера, поэтому новая палета с явно пропущенной печатью может перепечатываться. Локальное восстановление и полученный с другой станции источник работают без сети после успешного поиска.

## Регрессии и итоговое ревью

Один свежий reviewer всего изменения выявил четыре проблемы. Каждая воспроизведена тестом до исправления: ожидание одного источника блокировало следующие; удалённый источник нельзя было найти без сети; прерывание разрешения оставляло native delivery неизвестной; пропуск до отрисовки не сохранял источник. Исправлены очередь с курсором, нормализованные ключи поиска, атомарный SQLite trigger собственного разрешения и снимок закрытия. Дополнительный API тест воспроизвёл удаление единицы после закрытия: результат теперь conflict, а не retryable.

Все эти файлы плюс новые контракты повторены с исправленным test-env/указанием loopback-фикстуры: 99/99 PASS в 14 файлах, без пропусков. Typecheck/lint/build — PASS. ## Непроверенные внешние границы

Физическая печать/сканирование RAW и Windows, установка на станцию, Windows native build и production deploy здесь не выполнялись. Rust и Kotlin не изменены. Складские сборные палеты с несколькими товарами в этот этап не входят.

Для следующей beta сначала требуется deployment новых API и миграций, затем Station. Новые А4 пресеты нужно создать в библиотеке и выбрать для новой смены. Приёмка: закрытая смена с датой → перепечатка КМ; три А4 на реальном принтере; поиск палеты тремя способами, отмена и подтверждение; перезапуск без сети; отказ до отправки и неизвестная доставка без автоматического повтора.
