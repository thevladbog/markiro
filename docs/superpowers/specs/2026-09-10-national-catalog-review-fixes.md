# Проверка импорта и прямой перенос полей товара

Уточнение по обратной связи от 10 сентября 2026 года к импорту Национального каталога.

- Действие после выбора называется «Проверить выбранные товары». На этапе проверки
  открыт один товар; вкладки и кнопки перехода не сбрасывают выбранные поля и фото.
  Итог и применение охватывают весь выбранный набор. Новый снимок требует повторного
  подтверждения замены связи; решения переносятся только при однозначном совпадении
  значений, источника и зависимостей.
- Переключатель «Отображать только сопоставимые поля» исходно выключен. Он скрывает
  недоступные для переноса поля, сохраняя решения по остальным полям и фото.
- Два явных соответствия работают без регуляторной категории: точное название
  «Код продукции в ЕГАИС» соответствует основному коду ЕГАИС; «Срок годности, дней»
  соответствует сроку годности товара в днях. Эти однозначные соответствия имеют
  приоритет над дублирующими полями категории. Остальные характеристики
  по-прежнему требуют активной схемы.
- Код содержит ровно 19 цифр и сохраняется строкой. Срок — целое число от 1 до 3650
  дней по действующему контракту товара. Другие единицы не преобразуются. Разные
  идентификаторы или значения для одной подписи не выбираются автоматически;
  данные другой упаковки/GTIN не переносятся.
- Числовой ID атрибута берётся из прочитанной карточки, а не из предположения.
  Принятое решение и последующее наблюдение закрепляют этот ID, версию соответствия
  и снимок источника. Старые подтверждения не получают новые поля задним числом.
- После нового подтверждения статус изменений учитывает оба обычных поля, в том
  числе появление ранее отсутствовавшего значения. Изменение закреплённого ID или
  неоднозначные данные требуют новой проверки. Отсутствие атрибута в ответе ЧЗ
  само по себе не означает его удаление и не очищает значение товара.
- Слева показаны действительные значения товара. Только выбранные операции меняют
  товар. При смене основного кода ЕГАИС остальные коды сохраняются; лимит коллекции
  остаётся 20. Код, основной признак, происхождение, ревизия существующего профиля,
  связь и аудит фиксируются в одной транзакции. Изменение товара после подготовки
  вызывает конфликт, повтор подтверждённой операции не изменяет данные повторно.

Ранее подготовленные сравнения остаются неизменяемыми снимками. После выкладки
новые соответствия появятся в них через «Обновить данные для проверки» либо новую
подготовку товаров.

Отдельные исправления обратной связи: версии Station отображаются рядом, короткое
окно допускает прокрутку содержимого при доступных нижних действиях; карточка короба
в поиске кодов показывает номер связанной смены со ссылкой на её страницу.
Печать состава короба получает часовой пояс браузера, поэтому даты открытия,
закрытия и расформирования совпадают с карточкой, включая переход через полночь.
Самостоятельные запросы печати без часового пояса сохраняют прежний формат UTC.
