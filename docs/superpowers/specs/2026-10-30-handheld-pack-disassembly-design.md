# Расформирование упаковок площадки на ТСД Автонома

Статус: реализация по запросу владельца от 30.10.2026. Владелец подтвердил
сканирование любых коробов и палетов площадки, включая офис и другие ТСД.

## Сценарий

В главном меню ТСД в режиме Автонома появляется «Расформирование».
Оператор сканирует SSCC короба, производственного или складского палета.
Хост возвращает вид упаковки, товар, количество коробов/кодов, статус и причины
из справочника офиса. Оператор выбирает причину и отдельно подтверждает действие.
Сканирование на шаге выбора причины или подтверждения не меняет выбранную упаковку.
Успех показывается только после ответа хоста с номером проведённого документа.

Правила совпадают с офисом: короб и производственный палет принадлежат закрытой
смене; складской палет закрыт и не расформирован. Расформирование палета сохраняет
короба и их коды; расформирование короба освобождает его коды. Неизвестный SSCC,
открытая упаковка/смена, уже расформированная упаковка, демо/облачная история,
отозванное устройство, неактивный оператор и восстановление хоста запрещают запись.
Облачное приложение и существующие локальные исправления сохраняют свои сценарии.

## Решения реализации

- Новый сценарий читает актуальное состояние с хоста. При отсутствии связи новая
  операция не подтверждается. Существующие офлайн-очереди не меняются.
- Подтверждённое намерение сохраняется до сети в локальном журнале meta ТСД,
  привязанное к устройству/хосту/поколению и оператору. Повтор после обрыва или
  перезапуска отправляет тот же UUID и тело. Неопределённый результат нельзя
  выдать за успех или потерять при уходе с экрана. Новое сканирование доступно
  после получения определённого результата предыдущей операции.
- Новые device-маршруты доступны только живому устройству `handheld`, проверяют
  активного оператора и повторяют проверки под `BEGIN IMMEDIATE`. Они не используют
  офисную сессию и не создают фиктивного офисного пользователя.
- Lookup возвращает непрозрачный SHA-256 token состава и состояния. Apply проверяет
  тот же снимок под блокировкой; изменение после просмотра требует нового сканирования
  и подтверждения. Номер документа выдаётся только успешной атомарной операции.
- Создаётся обычный проведённый документ дезагрегации с отдельными FK устройства
  и оператора. Офисные FK остаются для офисных документов. Автор в офисе, карточках
  и акте показывает оператора и ТСД. Общие `apply_targets`, code releases, история,
  акты/XML и сохранённые файлы используются без параллельных правил расформирования.
- Новый document requestId уникален в пределах устройства; повтор сравнивает
  каноническое тело и возвращает прежний документ без повторной записи/номера/аудита.
  Ошибка повторного использования UUID с другим намерением — конфликт.
- Миграция перестраивает только заголовки документов с отложенными FK, сохраняет
  rowid, номера, дочерние строки, code releases, облачные связи и байты выгрузок.
  Проверка foreign_key_check и миграционный тест обязательны.
- API добавляется без изменения существующих wire-типов feed. Старый хост без
  маршрутов показывает понятную необходимость обновить хост; запрос не теряется.
- Тексты поставляются на русском и английском, «палет» с одной «л» в новом сценарии и существующих подписях ТСД.
  Интерфейс использует существующий Android design system и рассчитан на 360 dp.

## Приёмка

1. ТСД расформирует короб, производственный палет и палет из офиса/другого ТСД.
2. Палет освобождает короба; из них снова собирается палет. Короб освобождает коды,
   но сохраняет исторический состав и документ.
3. Потеря ответа, повторный тап, перезапуск процесса и повтор UUID не дублируют
   документ, номер или аудит. Старое поколение устройства не пишет новое состояние.
4. Изменение состава/статуса между lookup и apply ничего не расформирует.
5. В офисе видны документ, точный автор/устройство, акт и XML; сохранённые файлы
   скачиваются с теми же байтами. Старые офисные документы продолжают читаться.
6. Android unit/Compose, lint/APK и host/протокол/офисные проверки проходят.
   Физический ТСД, сканер, принтер и Windows остаются отдельной ручной приёмкой.
