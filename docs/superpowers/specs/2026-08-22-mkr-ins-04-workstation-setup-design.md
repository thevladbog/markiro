# MKR-INS-04 «Станция сканирования: настройка рабочего места» — дизайн

Дата: 2026-08-22
Статус: утверждён (brainstorming)
Предшественники: MKR-INS-01 (PR #220), MKR-INS-02 (PR #230), MKR-INS-03
(PR #235, merge `57093b131`) — конвейер категории `instruction` в main,
серию завершает этот документ.

## Цель

Четвёртая (финальная в серии) печатная инструкция: подготовка рабочего места
станции сканирования. Аудитория — НАЛАДЧИК/администратор, не оператор:
привязка станции к кабинету, подключение сканера и принтера, звук,
обновления станции. Контентная итерация по накатанному конвейеру.

## Решения (принятые в brainstorming)

- Сервисные потоки («Повторная привязка станции», «Сервисное подключение») —
  КРАТКО, без пошагового разбора: что это и когда применяется, с
  предупреждениями словами UI; выполнять только вместе с поддержкой.
- Кабинетская часть привязки — ТЕКСТОМ, без скриншотов админки (экран
  станции сам показывает три шага; скриншоты в серии — только станционные).
- Урок MKR-INS-03 применяется процессно: финальному whole-branch ревью
  задаётся явная линза «текст инструкции ↔ скриншоты ↔ i18n».

## 1. Документ

- Код `MKR-INS-04`, kind `instruction`, ревизия `2026.08/01`, effectiveDate
  `2026-08-22`, статус `active`, RU-only, маршрут
  `/instruktsii/nastroyka-rabochego-mesta/`.
- Контент — `packages/legal-documents/src/documents/station-workstation-setup.ts`.
  Цитаты интерфейса — строго из `apps/station/src/i18n/ru.json` (секции
  `enroll`, `setup`, `updates`, `work`). Структура секций:
  1. Назначение: выполняет наладчик/администратор при вводе рабочего места
     в строй или замене оборудования; операторская работа — MKR-INS-01…03.
  2. Привязка станции («Подключение станции»): шаги кабинета текстом
     (страница станции в кабинете администратора → восьмизначный код
     подключения → ввести или отсканировать на станции), «Подключаем…» →
     «Станция подключена»; callout: код недействителен/истёк → создать
     новый код в кабинете и ввести заново.
  3. Сканер: COM-подключение (порт, «Скорость (бод)», «Подключить сканер»,
     проверка тест-сканом до «Проверка сканера пройдена») либо режим
     «Без последовательного сканера (клавиатурный)»; когда какой выбирать.
  4. Принтер: «Подключение принтера» (Без принтера / Сеть (TCP) /
     COM-порт / Windows (USB)), параметры каждого, «Язык принтера»
     (ZPL/TSPL), «Тестовая печать» до фактически вышедшей этикетки;
     галка «Проверять каждую распечатанную этикетку сканированием» —
     включает сверку из MKR-INS-02.
  5. Звук: включить — станция подаёт звуковые сигналы вердиктов скана,
     операторы на линии полагаются на них.
  6. Обновления станции: индикатор «Обновления»/«Обновить …», центр
     обновлений («Проверить обновления», «Скачать и установить» — вручную),
     возраст релиза («Релиз вышел недавно» / «более 7 дней назад» /
     «более 30 дней назад; обновите при удобном случае»), блокер
     «Завершите активную смену перед установкой».
  7. Сервисные операции (кратко): «Повторная привязка станции» (ключ
     устройства будет удалён; локальные производственные записи останутся)
     и «Сервисное подключение» («Используйте только учётные данные от
     сервиса…») — редкие операции, только вместе с поддержкой Маркиро.
  8. Частые вопросы (definition-list): «(настроен, не обнаружен)» у
     сканера/принтера; «Установленные принтеры Windows не найдены» /
     «Обновить список»; тестовая этикетка не вышла; «Срок действия кода
     подключения истёк»; + контакты.
