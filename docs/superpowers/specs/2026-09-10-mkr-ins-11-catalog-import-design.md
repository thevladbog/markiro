# MKR-INS-11 «Кабинет: загрузка товаров из Национального каталога» — дизайн

**Дата:** 2026-09-10
**Статус:** утверждён (владелец выбрал «описать подключение как пререквизит»)
**Контекст:** вторая половина каталожной темы. MKR-INS-10 описал ручное
ведение карточки; этот документ закрывает второй способ завести товар —
загрузку из Национального каталога — и связь карточки с Честным Знаком.

## Объём

Документ для менеджера кабинета с правом «операции: запись». Сквозной
сценарий: от кнопки «Добавить из Национального каталога» до товара,
появившегося в каталоге с фотографией и группой продукции. Экраны:
панель импорта `/catalog/import` (три шага) и панель связи
`/catalog/:productId/chz`.

**Подключение к Честному Знаку** описывается как пререквизит: раздел
«Перед началом» перечисляет, что должно быть настроено, и показывает,
как выглядит экран, когда подключения нет. Сама настройка (агент КЭП,
токен True API) — работа администратора и в этот документ не входит.

**Вне объёма:** ручное ведение карточки (MKR-INS-10), очередь
несопоставленных товаров 1С (раздел «Интеграции»).

## Решение

### 1. Структура документа

Девять разделов.

1. **Назначение.** Что даёт загрузка из Национального каталога: карточка
   заполняется данными ЧЗ, подтягиваются группа продукции и фотография,
   между товаром и карточкой ЧЗ появляется связь. Плашка о демо-данных.
2. **Перед началом.** Пререквизиты: организация подключена к Честному
   Знаку, у сотрудника есть право на операции. Как выглядит стартовый
   экран, когда подключения нет или оно заблокировано, и к кому идти.
   Кадр: `import-unavailable`.
3. **Два способа загрузки.** «Загрузить мои товары» — весь каталог
   организации из ЧЗ; список GTIN — точечная загрузка. Почему способ
   бывает недоступен (возможности зависят от подключения). Кадр:
   `import-start`.
4. **Выбор товаров.** Прогресс загрузки списка, фильтры, колонка
   сопоставления и её значения (новый товар, уже в каталоге, связан с
   другой карточкой, архивный, неоднозначный, недоступный), лимит в сто
   позиций, кнопка перехода к проверке. Кадр: `import-selection`.
5. **Проверка перед применением.** Вкладки по товарам с индикаторами
   проблем, две колонки «Сейчас в Markiro» и «Предлагаемое значение»,
   ручное имя и начальная категория, флажки «связь без изменения полей»
   и подтверждение замены существующей связи, итоговая сводка. Кадры:
   `import-review`, `import-review-blocked`.
6. **Фотография.** Кандидаты из ЧЗ, выбор снимка, состояния «готовится»
   и «не загружено», причины отказа (несовпадение штрихкода,
   неподдерживаемый формат, недоступность). Кадр: `import-photo`.
7. **Результат.** Состояния операции, итоги по каждому товару и по фото,
   кнопка «Открыть товар в каталоге» — она ждёт, пока фото сохранится
   (поведение из PR #475), повтор неудавшихся позиций. Кадры:
   `import-result`, `import-result-photo`.
8. **Связь с Честным Знаком.** Что показывает столбец «Честный знак» в
   каталоге, панель связи: статус карточки ЧЗ, обновление сведений,
   отвязка, переход к сравнению карточки. Кадр: `chz-link`.
9. **Частые проблемы.** definition-list по классам отказов, а не по всем
   двадцати кодам: не удалось определить группу продукции; товар уже
   связан с другой карточкой; срок подготовки истёк и данные надо
   обновить; фото не загрузилось; загрузка прервана и её нужно
   восстановить.

Линза «текст ↔ кадры ↔ i18n»: цитаты берутся дословно из
`apps/admin/src/i18n/ru.json` (группа `pages.catalog.import.*` и
`pages.catalog.chz.*`) и должны быть видны на кадре своего шага.

### 2. Кадры и съёмка

Десять кадров в `packages/legal-documents/assets/instructions/mkr-ins-11/ru/`:

| id                      | Экран                                 |
| ----------------------- | ------------------------------------- |
| `import-unavailable`    | стартовый экран без подключения к ЧЗ  |
| `import-start`          | два способа загрузки                  |
| `import-selection`      | выбор товаров с сопоставлением        |
| `import-review`         | проверка: вкладки и сравнение полей   |
| `import-review-blocked` | позиция, которую применить нельзя     |
| `import-photo`          | секция фотографии в проверке          |
| `import-result`         | результат применения                  |
| `import-result-photo`   | результат с фото в состоянии ожидания |
| `chz-link`              | панель связи карточки с ЧЗ            |
| `chz-refresh-error`     | ошибка обновления сведений связи      |

**Инструмент.** Новый спек `tools/production-browser/tests/catalog-import.visual.spec.ts`
поверх существующего энтрипоинта `national-catalog-harness.html` (там
подключён `NationalCatalogIdentityBoundary`, без которого панель импорта
ведёт себя иначе). Конфиг — по образцу каталожного:
`catalog-import.playwright.config.ts`, свободный порт 61_596, скрипт
`test:catalog-import`.

Фикстуры и моки берутся из `apps/admin/test/national-catalog-fixtures.ts`
и семи существующих функциональных спек в `national-catalog-tests/` —
они уже провалидированы настоящими zod-схемами из `platform-contracts`,
поэтому форму ответов выдумывать не нужно. Перехват `/api/` — строгий:
неизвестный путь валит тест.

Кадры пишутся сразу в `mkr-ins-11/ru/`; съёмка только на русском —
документ выходит ru-only.

## Ограничения

- Playwright, docker и `gh` — вне песочницы; перед браузерными спеками
  нужен `pnpm --filter @markiro/platform-contracts build`.
- RU-кадры соседних документов дрейфуют субпиксельно: если прогон
  какой-то другой спеки их заденет, отличать дрейф по
  `magick compare -metric PAE` и откатывать.

## Критерии приёмки

1. Десять кадров сняты в `mkr-ins-11/ru/`; каждая цитата подтверждена в
   `ru.json` и видна на кадре своего шага (отчёт линзы в PR).
2. Новый спек зелёный, `unexpected` пуст во всех сценариях; тесты
   пакета, лендинга и deploy зелёные.
3. `artifacts:generate` публикует 32 файла, 31 старый байт-в-байт;
   `artifacts:verify` и повторный прогон с `--check` зелёные.
4. Страница `/instruktsii/katalog-zagruzka-iz-nk/` собирается, документ
   виден в RU-реестре и в группе «Кабинет» на хабе инструкций.
