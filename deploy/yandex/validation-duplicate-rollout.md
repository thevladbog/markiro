# Включение печати дубликатов Data Matrix

Режим проверки с печатью дубликата включается серверным флагом
`VALIDATION_DM_DUPLICATE_ENABLED`. По умолчанию он равен `false`.
Сообщение станции «Печать дубликатов недоступна для этой станции» появляется,
когда ответ `/shifts/planning-config` не содержит поддерживаемый протокол.
Настройки подключения принтера и DPI проверяются отдельно.

## Изменение настройки

1. Проверьте ACTIVE-версию `markiro-production-runtime` через metadata/list
   и совпадение имён ключей с `.env.production.example`.
2. Прочитайте только `VALIDATION_DM_DUPLICATE_ENABLED` через `payload get --key`.
   Для изменения одной настройки не требуется выгружать остальные значения.
3. Создайте новую версию с явным `base-version-id` текущей версии и единственным
   изменением: `VALIDATION_DM_DUPLICATE_ENABLED=true`. Остальные записи наследуются
   сервером; предыдущую версию сохраните для восстановления. Сверьте набор имён
   и значение изменённого флага после публикации.
4. Выпустите новый immutable release SHA и выполните защищённый
   `Deploy production` с точными run ID и SHA успешного `Publish production images`.
   Уже успешно развёрнутый SHA нельзя повторно активировать через `prepare`.
   Сохраните действующее состояние формы landing. Материализацию окружения
   и перезапуск API выполняет deployment; не запускайте их вручную.

Флаг общий для API: он разрешает создание новых смен с дубликатами всем
совместимым станциям. Печать и обязательность проверки по-прежнему выбираются
при создании смены. Параметры открытых смен и сохранённые задания не меняются.

## Подтверждение

- Дождитесь успешных readiness, smoke и finalize; сверьте `x-markiro-release-sha`.
- В авторизованном запросе `/shifts/planning-config` ожидается
  `validationPrintProtocol: "validation-dm-duplicate-v1"`.
- На станции повторно откройте настройки печати при создании смены: переключатель
  печати должен стать доступен. Выберите настроенный принтер, его DPI и подходящий
  шаблон 203/300 dpi. Проверку реальной печати и обратного сканирования фиксируйте
  отдельно от успешного deployment.

Для выключения создайте следующую версию Lockbox со значением `false` и примените
её следующим защищённым релизом. Флаг блокирует новые режимы печати; восстановление
и синхронизация уже сохранённых заданий продолжаются. Очереди и историю не удаляйте.

Полный протокол аппаратной приёмки:
[`validation-dm-duplicate.md`](../../docs/acceptance/validation-dm-duplicate.md).
