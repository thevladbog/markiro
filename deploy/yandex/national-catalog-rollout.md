# Выкладка настроек импорта Национального каталога

Флаги импорта применяются при запуске API из production Lockbox. Для изменения
настроек используйте новый опубликованный release SHA и защищённый
`Deploy production`: уже healthy SHA не проходит `prepare` повторно.
Этот deployment-документ входит в область `Publish production images`.

## Перед включением

Выполните защищённую read-only диагностику ЧЗ для согласованной организации и
известного GTIN и проверки из
[`national-catalog-import.md`](../../docs/runbooks/national-catalog-import.md#live-acceptance-before-limited-enablement).
Проверьте отдельно доступ к карточкам и права, фактическое окружение провайдера,
свежесть токена и результаты импорта. Один успешный диагностический отчёт
не доказывает все сценарии импорта, фотографий и восстановления.

## Изменение Lockbox

1. Через metadata/list проверьте текущую ACTIVE-версию и точный набор ключей
   из `.env.production.example`. Не запрашивайте payload для проверки имён.
2. Создайте новую версию с явным `base-version-id`. Все существующие записи
   наследуются сервером, предыдущая версия сохраняется для восстановления.
3. Для собственных карточек установите `NATIONAL_CATALOG_OWN_IMPORT_ENABLED=true`,
   для поиска по GTIN — `NATIONAL_CATALOG_GTIN_IMPORT_ENABLED=true`.
4. Для фотографий отдельно нужны `NATIONAL_CATALOG_IMAGE_IMPORT_ENABLED=true`
   и проверенные точные хосты `NATIONAL_CATALOG_IMAGE_ALLOWED_HOSTS`. Учитывайте
   каждый redirect. Не выводите хосты из примеров, фикстур или предположений.
   Международные домены указывайте в ASCII (Punycode), как в `new URL(url).hostname`.
   Для `национальный-каталог.рф` это `xn----7sbabas4ajkhfocclk9d3cvfsa.xn--p1ai`.
   Без проверенного списка оставьте фотографии выключенными.
5. Если нужен пустой список хостов, а Lockbox не сохраняет пустую строку,
   задайте один ASCII-пробел. `loadEnv` нормализует его в `[]`; имя записи
   остаётся обязательным для runtime inventory. Повторно сверьте набор имён.

Флаги глобальные. Доступность для конкретного арендатора дополнительно зависит
от его подключения, окружения и токена. Изменение этих флагов не разрешает
другие функции: например, `VALIDATION_DM_DUPLICATE_ENABLED` сохраняет прежнее значение.

## Выкладка и подтверждение

Передайте точные run ID и SHA успешной публикации в `Deploy production`, сохранив
действующее состояние формы landing. После обязательного approval дождитесь
миграций, запуска, readiness, public smoke и finalize.
Независимо сверьте `x-markiro-release-sha`, readiness API и доступность возможностей
импорта в согласованной организации. Проверку реальных карточек/фото отражайте
отдельно от HTTP smoke.

Для выключения используйте новую версию Lockbox и следующий защищённый релиз;
связи, receipts и историю не удаляйте. Выключение флагов перечисления само по себе
не останавливает refresh существующих связей: граница rollback описана в runbook
импорта.
